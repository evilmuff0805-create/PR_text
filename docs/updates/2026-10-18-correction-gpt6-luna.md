# 한국어 교정 모델을 GPT-6 Luna로 변경

한국어 맞춤법 교정의 기본 모델을 `gpt-6-luna`로 변경한다. 앞서 같은 합성 문장으로 비교했을 때 교정 품질의 확실한 우위는 확인하지 못했지만, 캐시 쓰기를 포함한 추정 원가는 약 53% 낮았다. 응답 중앙값은 약 42% 길었으므로 속도 개선으로 설명하지 않는다.

## 적용 범위

- 새 일반 단일·사람별 묶음·다화자 작업의 한국어 교정에 적용한다. 일반·묶음 전사는 `whisper-1`, 다화자 전사는 `gpt-4o-transcribe-diarize`를 유지한다.
- 기본 모델과 명시적으로 설정한 이전 `gpt-5.6-luna`는 `reasoning_effort: 'medium'`을 사용하며 sampling 옵션을 보내지 않는다. 프롬프트와 청크 크기, 반복·말투·숫자 보호 검사는 유지한다.
- 두 Luna의 지원·접근 오류 `400/403/404`에는 기존 `gpt-4o`로 폴백한다. 폴백 모델·실패·안전하게 원문을 남긴 미교정을 새 모델의 성공으로 계산하지 않는다.
- `GPT_CORRECTION_MODEL` 명시 설정은 계속 우선한다. 비한국어 처리·번역·아이디어 생성의 모델은 이번 교체 범위에 포함하지 않는다.
- 자막 시작·끝 시각, 단어 정렬, 파일별 0초 원점과 앞 무음, 일반 단일의 1초 이내 간격 표시, 묶음 내보내기 정책은 유지한다. 기존 기록을 재교정하거나 EP48의 후반 싱크 문제를 해결하는 변경은 아니다.

## 원가와 사용량

2026-10-18 공식 Standard 요율을 적용한 서버 추정값이다. 단위는 USD/100만 토큰이며 청구서 금액을 확정하는 계산은 아니다.

| 모델 | 일반 입력 | 캐시 읽기 | 캐시 쓰기 | 출력 |
| --- | ---: | ---: | ---: | ---: |
| GPT-6 Luna | 0.10 | 0.01 | 0.125 | 0.50 |
| GPT-5.6 Luna | 0.20 | 0.02 | 0.25 | 1.20 |
| GPT-4o | 2.50 | 1.25 | 일반 입력 요율 | 10.00 |

캐시 읽기·쓰기 토큰을 일반 입력에서 각각 제외해 중복 계산을 막는다. 출력에 포함된 추론 토큰은 다시 더하지 않는다. 두 Luna는 입력이 272,000토큰을 초과하면 전체 요청의 입력·캐시 요율을 2배, 출력을 1.5배로 계산한다. 없는 캐시 쓰기 값은 0이며, 비정상 토큰 값을 제거하고 캐시 합계가 입력을 넘지 않도록 정규화한다. 사용량 집계의 `cacheWriteTokens`는 JSON 저장·복원에도 유지한다.

공식 근거: [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna), [모델 마이그레이션](https://developers.openai.com/api/docs/guides/latest-model). 가격과 지원 범위는 확인 날짜 이후 달라질 수 있다.

## 검증과 한계

Node.js 22 전체 회귀 **603/603** 통과, 실패·취소·건너뜀 0이다. 운영 빌드 77개 모듈과 변경 공백 검사도 통과했다. 독립 오프라인 168항목에서 모델·옵션·폴백·토큰·장문 가격·반복 보호·시간 불변을 확인했다. 이전 GPT-6 Luna 원시 응답 282행을 새 코드에서 재생한 결과도 기존 보호 검사 이후 대사와 일치했다.

실제 제품 `correctTextWithUsage`의 기본 모델을 호출해 동결된 합성 93문장 × 3회와 고립형 진단 3회를 평가했다. 문장용 HTTP 15회와 저장된 합성 Whisper 응답 3건을 교정하는 HTTP 3회가 모두 성공했다. 공급자 응답은 모두 `gpt-6-luna`였으며 폴백·재시도·출력 길이 제한 종료는 0이었다. 실제 제품 요청 그대로 medium 추론을 사용하고 최대 출력 토큰·sampling을 추가하지 않았다.

| 282행 관측의 최종 결과 | 성공 | 전체 |
| --- | ---: | ---: |
| 교정 대상 | 129 | 132 |
| 보존 대상의 동결 정답 엄격 일치 | 149 | 150 |
| 단위 띄어쓰기 1건을 별도 검수한 보존 | 150 | 150 |

`나물을 묻혀서 → 나물을 무쳐서`는 청크 3/3과 고립형 3/3에서 교정됐다. 최종 의미·말투·반복 손실은 관측되지 않았다. 반복을 삭제한 원시 응답 1회는 가드가 원문으로 복원했으므로 미교정으로 기록했다. 음식 문맥의 다른 문장 미교정 2회와 합쳐 안전한 미교정은 3회다. 보존 대상의 엄격 불일치 1회는 `12cm → 12 cm`의 단위 공백뿐이었으며 동결 정답을 수정하거나 엄격 점수에 합산하지 않았다.

단일 파일과 사람별 두 파일의 저장된 실제 Whisper 응답을 새 교정·단어 정렬·SRT·ASS·ZIP까지 연결했다. 원본 응답과 파일별 0초 원점·앞 무음을 보존하고, 같은 교정 후보를 이전 코드에 넣었을 때의 시작·끝 및 대사 결과와 일치함을 확인했다. A/B 첫 자막의 내부 시작은 각각 2초/10초다. 단일의 공급자 단어 추정 시작 약 2.220초는 SRT 2.221초·ASS 2.23초로 올림해 기존 정밀도 정책을 유지한다. 2명 ZIP의 SRT·안내 파일과 CRC, 5,002큐 compact 내보내기도 검증했다. 추가 전사 API나 고객 음원·운영 DB는 사용하지 않았다.

이 실제 평가 18회의 사용량을 캐시 쓰기까지 포함해 계산한 원가는 약 $0.00630이다. 앞선 모델 간 비용·지연 비교와 이번 단일 모델 재검증은 분모가 다르므로 합산하지 않는다. 근거는 로컬 `.tools/qa-correction-luna-migration/`의 동결 평가·독립 검수·전체 테스트·빌드 기록에 보존한다. 정확한 배포 커밋과 운영 응답 검수는 해당 PR 및 로컬 배포 기록에서 확인한다.

실제 모델은 오류를 낼 수 있다. 보호 검사로 원문을 남긴 경우도 교정 실패로 기록한다. 작은 합성 표본의 성공을 모든 한국어 음원·고객 파일·Premiere의 프레임 정확도 보장으로 확대하지 않는다. 고객 음원이나 고객 대사와 API 키는 검증 문서에 포함하지 않는다.
