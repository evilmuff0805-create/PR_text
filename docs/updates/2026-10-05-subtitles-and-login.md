## 적용한 변경

### SRT 시작 기준점

- 모든 SRT 생성·재다운로드의 첫 항목에 `00:00:00,000 → 00:00:02,000`을 추가했다.
- 문구는 `0~2초 자막 시작 구간입니다!`, 글자 크기 48·굵게 태그를 지정했다.
- 원래 대사와 시간을 보존한다. TXT·ASS에는 시작 안내를 추가하지 않는다.
- SRT 스타일 적용 정도는 편집 프로그램에 따라 달라진다. 첫 2초에 실제 대사가 있으면 안내와 대사가 겹칠 수 있다.

### 로그인 직후 작업 페이지 이동

- 이메일·Google 로그인 성공 시 기본 목적지는 `/transcribe`다.
- 설정·자막 아이디어에서 요청한 명시적 복귀와 비밀번호 복구 흐름을 유지했다.
- 이메일 로그인은 사용자 정보 조회까지 성공한 뒤 새 세션과 이동을 확정한다.
- 로그인 흐름은 모의 API로 검증했다. 실제 계정의 Google 인증 완료를 검사한 결과는 아니다.

### 다화자 무음 구간 보존과 문장 분할

- 같은 화자의 짧은 대사를 합칠 때 최대 0.3초의 무음까지 덮던 원인을 재현했다.
- 다화자는 실제로 연속된 발화만 합치며 양수 무음 간격은 보존한다. 일반 전사의 기존 병합 기준은 유지했다.
- `뭐라고`의 마지막 `고`를 절 경계로 오인하던 원인을 재현했다.
- 다화자 한글 긴 문장에서 인용형·의문어·연결어·관형어가 뒤 표현과 함께 남도록 어절 경계를 선택한다.
- 검증한 출력:
  - `아니 아빠한테도 전화는 드렸는데`
  - `그냥 뭐라고 그러셨더라?`
- 검증한 비겹침 입력에서 SRT·ASS 모두 화자와 원문, 발화 전체의 시작·종료 시간을 보존했다.

## 적용 범위와 남은 한계

- 과거에 무음까지 합쳐 저장한 시간 경계는 재다운로드만으로 복구되지 않는다. 수정된 시간 처리는 새 다화자 변환으로 확인한다.
- 다화자 모델은 현재 단어별 시간이 아닌 구간 시간을 반환한다. 긴 구간 내부의 분할 시간은 글자 수 비례 추정이며, 원음과 단어별로 정확히 정렬된 결과를 보장하지 않는다.
- 문장 분할은 규칙 기반 개선이다. 형태소 분석이나 별도 음성 정렬을 수행한 것은 아니다.
- 기존 대사 겹침 정규화는 유지했다. 공급자가 한 구간 안에 포함한 무음과 동시 발화의 완전한 보존은 별도 음원 검증이 필요하다.
- 일반 Whisper의 무음 환각 `shadow` 관측 기능을 대사 삭제나 타임코드 수정에 사용하지 않았다.
