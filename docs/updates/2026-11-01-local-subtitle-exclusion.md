# 추가 AI 요청 없는 자막 제외·복원

일반 한국어 변환의 기존 전사·맞춤법 교정·선택 다듬기가 끝난 뒤 로컬 검토를 적용한다. 기존 Whisper/GPT 요청, 모델, 청크, 재시도와 재검토 정책은 유지한다. 문장 다듬기 미실행 문제와 추가 재전사는 이번 변경에 포함하지 않는다.

## 자동 제외와 검토

- 분산 반복과 원전사 위험 신호를 찾고, 원전사 문구·범위가 현재 자막에 유일하게 대응하는지 확인한다. 이웃 구간의 신뢰도를 차용하지 않는다.
- 낮은 공급자 신뢰도와 반복·압축·무발화 추정 근거에 더해, 원전사 전체 범위 앞뒤 0.25초의 모든 채널 샘플이 정확히 0일 때만 자동 제외한다. 여러 원본 행의 대사가 섞인 큐는 자동 제외하지 않는다.
- PCM 8/16/24/32 및 IEEE-float 32/64 WAV는 원래 샘플을 검사한다. MP3는 부동소수 디코딩, 채널·레이트·프레임 수 검증을 통과한 범위만 검사한다. 다운믹스·재샘플링·음량 임계값·노이즈 게이트는 사용하지 않는다.
- 낮은 음량·배경음·분석 실패·시간 범위 오류·한도 초과는 자동 제외 근거가 아니다. 분산 반복도 같은 문장이라는 이유만으로 삭제하지 않는다.
- 입력/디코딩 32MiB, 한 번의 로컬 분석 10초·스레드 1개, 창 20초·최대 12창·누적 60초로 제한한다. 이는 로컬 디코딩 한도이며 새 유료 API 검토 예산이 아니다.
- 기존 `SILENCE_OBSERVATION_MODE=shadow`는 관측 전용으로 유지한다. 기존 관측 후보를 자동 제외 정책으로 승격하지 않는다.

## 원문·시간과 내보내기

`subtitleReview.localExclusion`은 상태·사유와 당시 `text/start/end`를 보존한다. 상태는 `review`, `automatic`, `user`, `restored`다. 현재 문구·범위와 정확히 일치하며 화자 라벨이 없는 행에만 제외를 적용한다. 텍스트나 시간을 바꾸면 낡은 제외는 적용되지 않는다.

원본 행을 삭제하거나 빈 문자열로 치환하지 않는다. 편집 화면에서 개별 제외·복원을 명시적으로 선택하며, 저장·초안·캐시·기록 재열기에도 반영한다. 제외 상태는 음성 정답 확인이나 계정 권한의 증거가 아니다.

최종 분할·겹침 처리를 먼저 확정한 뒤 제외한다. 남은 대사의 범위를 다시 당기거나 비례 분할하지 않는다. 일반 단일의 1초 표시 유지가 제외된 구간을 다시 채우지 못하도록 장벽을 둔다. 그 밖의 기존 1초 규칙과 묶음·다화자 제외 정책은 유지한다.

한 큐가 여러 원본 행의 대사를 포함하면 일부 행만 제외할 수 없다. 사용자에게 함께 선택할 행을 안내하며 이웃 대사를 조용히 삭제하지 않는다. 전부 제외되면 SRT·ASS·TXT 다운로드를 막고 복원을 허용한다. 단일 내보내기와 묶음 ZIP은 같은 규칙을 사용한다.

## 검증 범위와 한계

극소 신호·PCM 최하위 비트·위상 상쇄·경계 여유·분석 실패·출처가 모호한 신뢰도·혼합 화자·내보내기 소유권·저장 복원·API 요청 불변을 검증한다. 실제 음원에서는 기존 저장 응답을 로컬에서 재생하고 전후 SRT/ASS와 파일 해시를 대조한다. 새 유료 AI 호출은 하지 않는다.

실제 소리가 있는 구간의 엉뚱한 대사를 올바른 대사로 복원하는 기능은 아니다. 그런 구간은 검토 대상으로 보존한다. 검토 표시, 자동 제외와 사용자가 확인한 제외를 별도로 보고한다. 로컬 CPU·메모리·처리시간은 발생할 수 있으며 인프라 비용까지 0이라고 설명하지 않는다.

## 최종 확인

- Node 22 전체 테스트 815/815, 독립 집중 검증 32/32와 마지막 ZIP 안내 회귀 1/1 통과. 프로덕션 빌드 78모듈과 공백 검사 통과.
- 합성 브라우저에서 자동 제외·복원, 사용자 제외, 저장·새로고침, 모든 구간 제외 후 다운로드 차단, 문구 변경 후 이전 제외 무효화를 확인했다. 373px·1280px 가로 넘침과 콘솔 오류가 없었다.
- 브라우저에서 받은 5인 ZIP을 직접 파싱해 CRC와 서버 파일 바이트 일치, 선택한 행만 제외, 나머지 4개 파일의 문구·시각 보존을 확인했다. 제외 후 빈 트랙과 실제 대사 미인식의 안내를 구분했다.
- 사용자 제공 음원에 대응하는 저장 결과 2건을 로컬 재생했다. 각각 358·429큐의 문구·시각과 SRT/ASS 바이트가 유지됐고, 의심 반복 10·1개는 음향 신호가 있어 자동 제외하지 않았다. 자동 제외는 두 결과 모두 0개다. 청취로 대사를 확정하거나 인식 오류가 복구됐다는 결과가 아니다.
- 기존 AI 관련 6개 모듈과 AI 처리 구간의 불변을 확인했다. 추가 AI 요청·토큰·음원 전송·운영 DB 쓰기·배포는 0이다. 실제 유료 API 평가, 프리미어 가져오기와 청취 평가는 이번 검증에 포함하지 않았다.

배포 사전 점검에서 실패한 MP3 디코딩의 임시 파일을 창마다 즉시 정리하도록 보강했다. 두 창 연속 실패에서도 다음 창을 시작하기 전에 이전 파일이 제거되는 회귀를 추가했다. 모델·분석 판정 기준·AI 요청은 바꾸지 않았다.
